Instalação das Ferramentas

Esta página reúne o processo de configuração inicial das três ferramentas de segurança usadas no fluxo do projeto: Trivy, Semgrep e Gitleaks. A ideia é que você consiga sair do zero até um ambiente validado, com comandos já organizados em uma ordem prática de execução, sem precisar procurar cada etapa em outra página.

O conteúdo foi pensado para dois cenários: uma instalação rápida, feita por meio do script disponibilizado pelo projeto, e uma instalação manual, caso você prefira acompanhar cada passo e entender exatamente o que está sendo configurado. Em ambos os casos, o objetivo final é o mesmo: deixar o ambiente pronto para análise local de dependências, código-fonte e segredos.

Windows ou outras distribuições do linux

Os comandos abaixo foram escritos para Linux/macOS. Se você estiver em Windows, a forma mais estável de seguir este guia é usando o WSL 2 com uma distribuição Linux instalada. Também é importante ter acesso à internet, pois o processo baixa versões recentes das ferramentas e depende disso para concluir a configuração.

1. Script de Configuração de Ambiente [INSTALAÇÃO RÁPIDA]

Se você quer reduzir a configuração manual e começar mais rápido, use o script de ambiente. Ele foi montado para executar os mesmos passos documentados nesta página, mas de forma automatizada, o que diminui a chance de esquecer alguma etapa ou instalar uma versão diferente da esperada.

O script instala os binários em ~/.local/bin, não depende de sudo e busca automaticamente as versões mais recentes de Trivy e Gitleaks. Ele também prepara o ambiente para que os comandos fiquem disponíveis no seu terminal após a inclusão desse diretório no PATH.

Use essa opção quando o ambiente estiver limpo, quando você quiser padronizar uma máquina nova ou quando o objetivo for simplesmente validar rapidamente o funcionamento das ferramentas antes de seguir para a triagem das vulnerabilidades.

Arquivo disponível: assets/scripts/script.sh

Baixar script.sh

Antes de rodar o script no Linux, valide se o pipx já existe no ambiente. Esse pré-requisito é importante para o Semgrep ser instalado corretamente. Se o pipx não estiver disponível, solicite ao administrador a instalação abaixo:

Bash 
sudo apt-get update && sudo apt-get install -y python3 pipx
Executando o Script

Antes de rodar o script, certifique-se de estar no mesmo diretório onde o arquivo foi salvo. O comando chmod +x script.sh serve para marcar o arquivo como executável, permitindo que o terminal o reconheça como um programa que pode ser iniciado. Em seguida, o comando ./script.sh executa o script na pasta atual. O prefixo ./ é importante porque informa ao terminal que o arquivo está no diretório em que você está trabalhando agora.

Na prática, o fluxo correto é: abrir o terminal, navegar até a pasta onde o arquivo foi baixado e só então executar os comandos. Por exemplo, se o arquivo estiver em uma pasta chamada Downloads, primeiro entre nela com cd Downloads e depois rode os dois comandos abaixo. Se o script estiver em outro caminho, ajuste a navegação para a pasta correspondente antes de iniciar a execução.

Bash 
chmod +x script.sh
./script.sh

Antes de executar, confirme se o arquivo foi baixado corretamente, se você está na pasta onde o script.sh foi salvo e se o terminal tem permissão para tornar o arquivo executável. Após a execução, o esperado é que o script conclua sem erros e deixe os binários acessíveis para a etapa de validação no fim desta página.

1.1 Login no Semgrep [APÓS EXECUTAR O SCRIPT]

Após a execução bem-sucedida do script, o Semgrep estará instalado e pronto para uso. No entanto, para acessar recursos avançados e manter sua sessão autenticada durante os scans, você precisa fazer login com sua conta Semgrep.

Execute o comando de login no terminal. Você será redirecionado para o navegador para autenticar com seu provedor (GitLab, GitHub, etc.) e criar ou selecionar uma organização.

Autenticação Obrigatória Semgrep Pro Engine

Semgrep requer login para usar a Pro Engine e as regras avançadas. Execute:

Bash 
semgrep login

O guia completo acima mostra passo a passo como realizar o login. Após completar todas as etapas e confirmar a autenticação no terminal, você estará pronto para usar o Semgrep com sua sessão autenticada.

2. Git Hooks no Fluxo

Depois que as ferramentas estiverem instaladas, o repositório passa a usar Git Hooks como uma camada de controle local antes do envio das alterações. Na prática, isso significa que, ao tentar criar um git commit, o hook pode acionar verificações com Trivy, Semgrep e Gitleaks para impedir que problemas óbvios avancem para o repositório remoto. Essa abordagem reduz retrabalho e traz a checagem de segurança para mais perto do momento em que o código foi alterado.

Execute o comando abaixo dentro da raiz do projeto para apontar o Git para a pasta de hooks personalizada. Sem essa configuração, o hook local não será encontrado e o fluxo de validação não será aplicado como esperado.

Bash 
git config core.hooksPath .githooks

Resultado esperado: se houver risco alto detectado no commit, o hook bloqueia localmente e o desenvolvedor corrige antes do push.

Se você estiver clonando o projeto em uma máquina nova, esse ajuste precisa ser feito no repositório local. Depois disso, vale testar um commit simples para confirmar que o hook está carregando e que as ferramentas instaladas respondem corretamente antes de seguir com mudanças maiores.

3. Instalação das Ferramentas [INSTALAÇÃO MANUAL]

A instalação manual é útil quando você quer revisar cada comando, entender o que está sendo baixado ou adaptar apenas uma das ferramentas ao seu ambiente. O passo a passo abaixo segue a mesma ordem do script, mas separa cada componente para facilitar o diagnóstico caso algo falhe durante a execução.

3.1 Trivy

O Trivy é a ferramenta de SCA usada para localizar vulnerabilidades em dependências, imagens de container e arquivos de infraestrutura como código. Nesta etapa, o foco é garantir que o binário fique instalado em um caminho acessível pelo terminal, para que você consiga executá-lo sem precisar informar o caminho completo toda vez.

Bash 
TRIVY_VERSION=$(wget -qO- https://api.github.com/repos/aquasecurity/trivy/releases/latest | sed -n 's/.*"tag_name": "\([^"]*\)".*/\1/p' | head -n1 | sed 's/^v//')
wget -q "https://github.com/aquasecurity/trivy/releases/download/v${TRIVY_VERSION}/trivy_${TRIVY_VERSION}_Linux-64bit.tar.gz"
tar -xf "trivy_${TRIVY_VERSION}_Linux-64bit.tar.gz" trivy
mkdir -p "$HOME/.local/bin"
install -m 0755 trivy "$HOME/.local/bin/trivy"
rm -f "trivy_${TRIVY_VERSION}_Linux-64bit.tar.gz" trivy

3.2 Semgrep

O Semgrep faz análise estática de código, identificando padrões inseguros antes que eles cheguem à execução. Ele é especialmente útil para encontrar problemas de lógica, uso incorreto de funções e práticas que costumam gerar vulnerabilidades em aplicações backend e frontend.

Bash 
# Se pipx nao existir no ambiente, solicite instalacao ao administrador:
# apt-get update && sudo apt-get install -y python3 pipx

pipx ensurepath
pipx install semgrep || pipx upgrade semgrep
Autenticação Obrigatória Semgrep Pro Engine

Semgrep requer login para usar a Pro Engine e as regras avançadas. Execute:

Bash 
semgrep login

Caso a autenticação seja necessária no seu ambiente, faça o login antes de executar regras avançadas. Se o comando não estiver disponível de imediato, confira se o pipx foi instalado e se o diretório de binários do usuário foi incluído no PATH do shell atual.

3.3 Gitleaks

O Gitleaks é a ferramenta de detecção de segredos do projeto. Ele ajuda a identificar credenciais, tokens, chaves de API e outros dados sensíveis que possam ter sido inseridos no código ou no histórico do Git. A instalação manual aqui segue uma lógica simples: baixar a versão mais recente, mover o binário para o diretório local do usuário e validar a instalação em seguida.

Bash 
GITLEAKS_VERSION=$(wget -qO- https://api.github.com/repos/gitleaks/gitleaks/releases/latest | sed -n 's/.*"tag_name": "\([^"]*\)".*/\1/p' | head -n1 | sed 's/^v//')
wget -q "https://github.com/gitleaks/gitleaks/releases/download/v${GITLEAKS_VERSION}/gitleaks_${GITLEAKS_VERSION}_linux_x64.tar.gz"
tar -xf "gitleaks_${GITLEAKS_VERSION}_linux_x64.tar.gz"
mkdir -p "$HOME/.local/bin"
install -m 0755 gitleaks "$HOME/.local/bin/gitleaks"
rm -f "gitleaks_${GITLEAKS_VERSION}_linux_x64.tar.gz" LICENSE README.md
gitleaks version

4. Validação Rápida

A etapa de validação serve para confirmar que o terminal reconhece os comandos instalados e que o diretório ~/.local/bin está visível na sessão atual. Se algum comando não responder, isso normalmente indica um problema de instalação, de permissão ou de configuração do PATH.

Bash 
export PATH="$HOME/.local/bin:$PATH"
trivy --version
semgrep --version
gitleaks version

Se o Trivy e o Gitleaks retornarem a versão esperada, a instalação principal está funcionando. No caso do Semgrep, a resposta depende de o pipx estar instalado e de a ferramenta ter sido concluída com sucesso. Se algo falhar nessa etapa, volte ao bloco correspondente e revise o comando executado, a conexão com a internet e o caminho definido no terminal.
